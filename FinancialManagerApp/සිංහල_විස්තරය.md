## 🚀 ස්ථාපන උපදෙස්

### පියවර 1: Dependencies ස්ථාපනය කරන්න
```bash
cd /workspace/FinancialManagerApp
npm install
```

### පියවර 2: Android එකේ ධාවනය කරන්න
```bash
npx react-native run-android
```

### පියවර 3: APK ගොඩනඟන්න
```bash
cd android
./gradlew assembleDebug
# හෝ
./gradlew assembleRelease
```

APK ගොනුව පිහිටීම:
```
android/app/build/outputs/apk/debug/app-debug.apk
```

### භාවිතා කළ තාක්ෂණයන්
- **Framework**: React Native 0.72.0

- **Styling**: StyleSheet API

- Android 5.0 (API Level 21) හෝ ඊට වැඩි
- 50MB ඇතුළත් ඉඩ
